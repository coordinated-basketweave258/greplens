## 🎯 What is greplens?

Greplens is a tool for security management. It allows you to track vulnerabilities in your software projects. You get a central dashboard to see problems and check rules. You can run scans to find risks in your code. This helps you keep your applications safe without complex manual checks. It runs on your own computer or server, so your data stays under your control.

## 🛠️ Performing your first scan

You can scan a folder on your computer for security issues. Follow these steps to begin:

1.  Open the greplens dashboard in your browser.
2.  Navigate to the Projects menu.
3.  Click the Add New Project button.
4.  Select the folder on your computer that contains your code.
5.  Press the Save button to register the project.
6.  Return to the dashboard list.
7.  Find your project and click the Scan button.
8.  Wait for the process to complete. The status indicator will show when the scan finishes.

## 📊 Reviewing findings

Once the scan finishes, click on the project name. You will see a list of findings categorized by severity.

*   **Critical:** These issues require immediate attention.
*   **High:** Fix these faults as soon as possible.
*   **Medium:** Look at these when time permits.
*   **Low:** These represent minor observations.

Click on any finding to see a description. The tool shows you exactly where the issue exists in your file. Use the provided suggestions to fix the code.

## ❓ Frequently Asked Questions

**Does this software send my data to the internet?**
No. Greplens is a self-hosted tool. All scans happen on your local machine.

**Can I use this for multiple projects?**
Yes. You can add as many project folders as your disk space allows.

**What do I do if the scan takes too long?**
Large projects contain many files. This takes time to analyze. Let the process run in the background. If it hangs, close the application and start it again.

**Do I need an internet connection to run scans?**
Once installed, you can run most scans offline. You only need the internet to download updates or fetch the latest security rule definitions.

## 🛡️ Troubleshooting

If you encounter errors, check the logs. Navigate to the Settings menu and click on the Logs tab. The error messages will tell you if a file is blocked or if disk space is low. Ensure that your antivirus software does not block the application. You might need to add a folder exclusion in your security settings if the scan stops unexpectedly. Contact support if the problem persists.
